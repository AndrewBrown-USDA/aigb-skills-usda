`install: invalid skill selection`, while the existing smoke compatibility check
expects `/Skill(s) not found/`. `src/cli.js` now preserves the loadout behavior
and translates only that CLI diagnostic to the established compatibility text.
The required checks were rerun; `npm test` was allowed one retry as specified.
