# Authoring Best Practices

Use this reference when designing or restructuring a skill.

Start from real tasks, user corrections, execution traces, and failure cases. State the intended outcome, the smallest useful scope, explicit gotchas, and one recommended default. Keep procedures actionable without explaining general framework behavior the agent already knows.

Prefer deterministic scripts and validation loops for repeatable work. Put durable detail in one canonical reference, keep routing-critical constraints inline, and add examples only when they clarify a decision or edge case.

Before delivery, test the skill against realistic prompts, remove redundant prose, and preserve known failure patterns so later revisions do not reintroduce them.
