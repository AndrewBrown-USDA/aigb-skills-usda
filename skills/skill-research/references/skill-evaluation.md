# Skill Evaluation

Use this reference when comparing skill revisions or outputs.

Start with two or three realistic tasks. Compare with-skill output against the prior version or a no-skill baseline. After observing initial outputs, add objective assertions for behavior that distinguishes the conditions; remove assertions that both conditions satisfy.

Track quality, token use, duration, and qualitative findings. Record failure patterns and regressions, then repeat the evaluation after each meaningful revision. Keep cases small, reproducible, and tied to the skill's intended boundary.
