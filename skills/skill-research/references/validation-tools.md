# Validation Tools

Use this reference when running interoperable skill checks.

```text
skills-ref validate path/to/skill
skills-ref read-properties path/to/skill
skills-ref to-prompt path/to/skill-a path/to/skill-b
```

`skills-ref` checks standard skill properties such as frontmatter and naming. It does not replace repository validation for Markdown-link integrity, citation completeness, reference depth, catalog metadata, or packaged-skill policy. Run the repository's documented validation commands as well.
